# Inline FDC Agent

설비 데이터를 **자연어로 묻고 분석**하는 도구입니다.

DB 에 직접 붙지 못하는 환경을 전제로 만들어졌습니다. 그래서 모델이 값을 지어내는
대신, **필요한 데이터를 조회 SQL 과 함께 요청**하고 사용자가 그 결과를 붙여넣으면
그것을 근거로 분석합니다.

## 화면 구성

| 위치 | 이름 | 역할 |
| --- | --- | --- |
| 왼쪽 | 데이터 패널 | 요청받은 데이터 · 등록된 데이터(설비 · 구간 · 종류별 그룹) |
| 가운데 | 채팅 | 질문과 답변, 표 · 차트, 추천 후속 질문 |
| 오른쪽 | 설비 패널 | 지금 쥔 데이터에 등장하는 설비와 그 분석 이력 |

## 지금 쓸 수 있는 것

- **분석 대화** — 질문 → 답변, 표·차트 첨부, 추천 후속 질문
- **데이터 요청 왕복** — 요청 카드의 SQL 복사 → 사내에서 실행 → 결과 붙여넣기 →
  이어서 분석. 이미 받은 데이터는 다시 요청하지 않습니다
- **데이터 등록 3경로** — [+ 데이터 추가] · 화면에서 **Ctrl+V** · 파일 끌어놓기
- **체크로 첨부 제어** — 체크된 데이터만 질문과 함께 나갑니다
- **그룹 보기** — 등록된 데이터가 `설비 · 구간 · 종류` 묶음으로 쌓입니다
- **넓게 보기** — 데이터 패널을 넓혀 목록과 표 내용을 나란히 봅니다
- **대화 이력** — 브라우저에 자동 저장, 상단 ≡ 에서 다시 열기
- **설비 카드** — 설비별로 "무엇을 언제 봤는지" 이력이 쌓이고, 줄을 누르면 왼쪽에서
  그 데이터로 안내합니다 *(현재는 예시 데이터로 동작합니다)*

## 준비 중인 것

- **설비 카드 실연동** — 지금은 예시값입니다. 요청이 설비 · 구간 · 종류를 함께 실어
  보내면 실제 데이터에서 카드가 만들어집니다
- **설비 자세히** — 카드에서 여는 확장 화면(무엇을 담을지 정하는 중)
- **보기 방식 전환** — 따로 보기 / 다른 기준으로 묶어 보기, 그리고 각 영역의 **필터**
- **정해진 쿼리 풀** — 요청 가능한 조회를 목록으로 제한하고, 값만 채워 바로 실행할 수
  있는 SQL 로 만들어 드립니다
- **직접 붙여넣은 데이터의 분류** — 지금은 요청으로 받은 데이터만 그룹에 들어갑니다
- **요약 리포트 · 이미지 업로드**
- **로그인 · 권한**(FDC.read / FDC.config / FDC.report)

## 쓰는 순서

1. 채팅에 질문합니다.
2. 데이터가 더 필요하면 왼쪽에 **요청 카드**가 뜹니다 — SQL 을 복사해 사내에서 실행하세요.
3. 결과를 카드에 붙여넣으면 등록됩니다. 채팅에 "등록 완료"라고 알려주면 이어서 분석합니다.
4. 오른쪽 설비 패널에서 이력을 누르면, 그때 본 데이터가 왼쪽에서 다시 열립니다.

> 오른쪽 이력의 **`요청됨`** 은 "요청은 나갔고 아직 안 채워졌다"는 뜻입니다. 누르면
> 왼쪽의 해당 요청 카드로 이동합니다.

## 저장과 보안

- 입력한 데이터와 대화는 **브라우저에만** 저장됩니다(기기 간 동기화 없음).
- 서버에는 질문 시점에 체크된 내용만 전달되며 따로 보관하지 않습니다.
- 답변은 분석 보조입니다 — **공정 결정은 담당자 검토를 거쳐** 진행하세요.
